# 橋梁管理システム

市区町村向け橋梁データベース管理システムです。国土交通省「橋梁定期点検要領」に対応した橋梁台帳・点検記録・写真管理が行えます。

## GitHub Codespaces でワンクリック起動

**下のボタンをクリックするだけで、セットアップ不要で起動できます。**

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/yoshiharu57/Daityou)

起動後は自動で以下が実行されます：
1. Python / Node.js の依存パッケージをインストール
2. フロントエンドをビルド
3. サンプルデータ（橋梁4件）を投入
4. バックエンド（ポート8000）・フロントエンド（ポート3000）を起動
5. **ブラウザが自動で開く**

## 管理できる情報

### 橋梁基本情報
| 項目 | 説明 |
|---|---|
| 管理番号 | 橋梁ID（例: BR-001） |
| 橋梁名 / 橋梁名カナ | 漢字名・カタカナ名 |
| 路線名 / 道路種別 | 市道・県道・国道など |
| 管理者 | 管理担当課・部署名 |
| 所在地 / 緯度経度 | 住所・Google Map連携 |

### 構造諸元
| 項目 | 説明 |
|---|---|
| 橋梁形式 | RC単純T桁橋・PC単純桁橋など |
| 上部工構造 | RC桁橋・PC桁橋・鋼桁橋など |
| 下部工構造 | 逆T式橋台・T型橋脚・直接基礎など |
| 材料 | 鉄筋コンクリート・鋼など |
| 橋長 / 幅員 | メートル単位 |
| 建設年次 | 建設年・橋齢の自動計算 |

### 点検履歴
| 項目 | 説明 |
|---|---|
| 点検年月日 / 点検種別 | 定期・緊急・詳細点検など |
| 健全性診断結果 | 判定区分 I〜IV |
| 次回点検予定日 | 一覧からも確認可能 |
| 損傷記録 | 部材種別・損傷種別・損傷程度 |
| 点検写真 | ドラッグ＆ドロップアップロード・PDF対応 |

## 主な機能

### 橋梁台帳一覧
- 管理番号・橋梁名・路線名・所在地を一覧表示
- **前回点検年月・次回点検予定日**を一覧で確認
- 健全性区分（I〜IV）をカラーバッジで表示
- 統計カード（健全性別の橋梁数を集計）
- 橋梁名・管理番号・場所でキーワード検索

### 橋梁詳細（橋梁名クリックで開く）

| タブ | 内容 |
|---|---|
| 橋梁台帳 | 全諸元・建設情報・Google Mapリンク・最新点検情報 |
| 点検記録 | 国交省様式準拠の点検記録・損傷記録・所見管理 |
| 写真 | ドラッグ＆ドロップアップロード・ギャラリー・PDF対応 |

### 健全性区分（国土交通省準拠）
| 区分 | 状態 | 説明 |
|---|---|---|
| I | 健全 | 損傷が認められないか軽微 |
| II | 予防保全段階 | 予防保全の観点から措置が必要 |
| III | 早期措置段階 | 早期に措置を講ずべき状態 |
| IV | 緊急措置段階 | 緊急に措置を講ずべき深刻な状態 |

## ローカルでの起動方法

**必要なもの:** Python 3.11+、Node.js 20+

```bash
# 依存パッケージのインストール・ビルド・起動をまとめて実行
./start_dev.sh
```

| URL | 内容 |
|---|---|
| http://localhost:3000 | メイン画面 |
| http://localhost:8000/docs | API仕様書（Swagger UI） |

## 技術構成

```
├── backend/               # Python FastAPI + SQLite
│   ├── main.py            # アプリケーションエントリポイント
│   ├── models.py          # データベースモデル（橋梁・点検・損傷・写真）
│   ├── schemas.py         # Pydantic スキーマ
│   ├── seed_data.py       # サンプルデータ投入スクリプト
│   ├── routers/           # API エンドポイント
│   │   ├── bridges.py     # 橋梁 CRUD API
│   │   ├── inspections.py # 点検・損傷記録 API
│   │   └── photos.py      # 写真アップロード API
│   └── uploads/           # アップロード写真の保存先
└── frontend/              # React 18 + Bootstrap 5 + Vite
    └── src/
        ├── api.js         # API クライアント・定数定義
        ├── pages/         # 一覧・詳細・登録フォーム
        └── components/    # 台帳・点検記録・写真ギャラリー
```
