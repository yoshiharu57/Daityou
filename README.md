# 橋梁管理システム

市区町村向け橋梁データベース管理システムです。国土交通省定期点検要領に対応した点検記録・写真管理ができます。

## GitHub Codespaces でワンクリック起動

**下のボタンをクリックするだけで、セットアップ不要で起動できます。**

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/yoshiharu57/Daityou)

起動後は自動で以下が実行されます：
1. Python / Node.js の依存パッケージをインストール
2. フロントエンドをビルド
3. サンプルデータ（橋梁3件）を投入
4. バックエンド（ポート8000）・フロントエンド（ポート3000）を起動
5. **ブラウザが自動で開く**

---

## 主な機能

### トップページ（橋梁一覧）
- 管理番号・橋梁名・路線名・所在地を一覧表示
- Google Map リンクから位置を確認
- 前回点検年月・健全性区分（I〜IV）を表示
- 橋梁名・管理番号・場所でキーワード検索

### 橋梁詳細（橋梁名クリックで開く）

| タブ | 内容 |
|---|---|
| 橋梁台帳 | 構造諸元・建設年次・管理者情報・Google Mapリンク |
| 点検記録 | 国交省様式準拠の点検記録・損傷記録・所見管理 |
| 写真 | ドラッグ＆ドロップアップロード・ギャラリー・PDF対応 |

### 健全性区分
| 区分 | 状態 |
|---|---|
| I | 健全 |
| II | 予防保全段階 |
| III | 早期措置段階 |
| IV | 緊急措置段階 |

## ローカルでの起動方法

**必要なもの:** Python 3.11+、Node.js 20+

```bash
# 依存パッケージのインストール・ビルド・起動をまとめて実行
./start_dev.sh
```

| URL | 内容 |
|---|---|
| http://localhost:3000 | メイン画面 |
| http://localhost:8000/docs | API仕様書（Swagger UI） |

## 技術構成

```
├── backend/          # Python FastAPI + SQLite
│   ├── main.py
│   ├── models.py     # データベースモデル
│   ├── routers/      # API エンドポイント
│   └── uploads/      # アップロード写真の保存先
└── frontend/         # React 18 + Bootstrap 5 + Vite
    └── src/
        ├── pages/    # 一覧・詳細・登録フォーム
        └── components/  # 台帳・点検記録・写真ギャラリー
```
