# 建設コンサルタント 案件管理システム

建設コンサルタントの営業職向け受注案件管理システムです。

## GitHub Codespaces でワンクリック起動

**下のボタンをクリックするだけで、セットアップ不要で起動できます。**

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/yoshiharu57/Daityou)

起動後は自動で以下が実行されます：
1. Python / Node.js の依存パッケージをインストール
2. フロントエンドをビルド
3. サンプルデータ（案件5件）を投入
4. バックエンド（ポート8000）・フロントエンド（ポート3000）を起動

---

## 主な機能

### ダッシュボード
- 案件数サマリー（総案件・進行中・期限超過・受注金額合計）
- 期限超過・期限間近のアラートバナー
- ステータス別フィルタータブ（進行中 / 期限間近 / 期限超過 / 完了 / すべて）
- 工期残日数の自動計算・色分け表示（赤：超過、黄：30日以内、青：通常）
- 進捗率バー付き案件一覧テーブル

### 案件一覧
- 業務ナンバー・案件名・発注機関・相手先担当者名
- 契約日・工期開始日・工期終了日・残日数
- 担当 / 主任技術者 / 照査技術者
- 業務進捗率（カラーバー）・受注金額・ステータス
- キーワード検索・ステータス/種別/担当者フィルター
- 列クリックによるソート
- **CSV出力機能**

### 案件登録・編集
- 業務ナンバー・案件名・業務種別
- 発注機関・相手先担当者
- 契約日・工期開始/終了日
- 担当/主任技術者/照査技術者（候補入力補完付き）
- 受注金額・ステータス
- 進捗率スライダー
- メモ・備考欄

### 案件詳細
- 全情報の閲覧
- 進捗率ワンクリック更新
- **活動履歴（営業日報機能）**
  - 打合せ・提出・現地調査・電話・メールなどを記録
  - 次のアクションメモ付き
  - タイムライン表示

### 営業支援機能
| 機能 | 内容 |
|---|---|
| 工期残日数自動計算 | 今日から工期終了日までの残日数を常時表示 |
| アラート表示 | 期限超過・30日以内の工期終了をダッシュボードで警告 |
| 色分け表示 | 赤（超過）/ 黄（間近）/ 青（通常）/ グレー（完了）|
| 受注金額集計 | 全案件の受注金額合計をダッシュボードに表示 |
| CSV出力 | 案件一覧をExcel対応CSVでダウンロード |
| 活動履歴 | 案件ごとに打合せ・訪問記録を時系列管理 |
| 担当者別フィルター | 担当/主任/照査のいずれかで絞り込み |
| ステータス管理 | 進行中 / 完了 / 中断の3ステータス |

## ローカルでの起動方法

**必要なもの:** Python 3.11+、Node.js 20+

```bash
./start_dev.sh
```

| URL | 内容 |
|---|---|
| http://localhost:8000 | メイン画面 |
| http://localhost:8000/docs | API仕様書（Swagger UI） |

## 技術構成

```
├── backend/          # Python FastAPI + SQLite
│   ├── main.py
│   ├── models.py     # Project / ActivityLog モデル
│   ├── schemas.py    # Pydantic スキーマ
│   └── routers/
│       ├── projects.py       # 案件 CRUD + 統計API
│       └── activity_logs.py  # 活動履歴 CRUD
└── frontend/         # React 18 + Bootstrap 5 + Vite
    └── src/
        ├── pages/
        │   ├── DashboardPage.jsx    # ダッシュボード
        │   ├── ProjectListPage.jsx  # 案件一覧
        │   ├── ProjectFormPage.jsx  # 登録・編集フォーム
        │   └── ProjectDetailPage.jsx # 詳細・活動履歴
        └── api.js   # APIクライアント
```
